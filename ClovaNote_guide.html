회의 녹음부터
스크립트 다운로드까지

ClovaNote로 미팅을 녹음(또는 음성 파일 업로드)하고, 자동 변환된 스크립트를 파일로 내려받는 전체 과정을 화면 캡처와 함께 정리했습니다. 위 탭에서 단계를 선택하세요.

대상: TS Sales 팀원
소요 시간: 약 5분
총 6단계
본 가이드는 ClovaNote 웹(clovanote.naver.com) 화면 기준입니다. 모바일 앱에서도 같은 방식으로 녹음할 수 있으나 메뉴 위치는 다를 수 있습니다. 화면 캡처는 2026.10.16 시점의 영문 UI입니다.
OVERVIEW

한눈에 보기

ClovaNote는 음성을 텍스트(스크립트)로 자동 변환해 주는 회의록 서비스입니다. 회의 내용을 직접 받아 적을 필요 없이, 녹음 → 스크립트 확인 → 파일 다운로드 세 단계면 됩니다.

STEP 01 · 02

접속하고 새 노트 만들기

웹 브라우저에서 ClovaNote에 로그인한 뒤, 녹음할 새 노트를 만듭니다.

01
ClovaNote 접속 후 로그인
브라우저에서 clovanote.naver.com 에 접속해 우측 상단의 Log in 을 누릅니다. 처음이라면 Try for personal use 로 시작할 수 있습니다. (모바일은 App Store / Google Play 에서 앱 설치)
02
Home 에서 New note 선택
로그인하면 Home 화면이 열립니다. 좌측 상단의 청록색 버튼에서 New note 를 눌러 새 노트를 만듭니다. 좌측에는 폴더(예: Vantive)와 남은 요약 횟수 · 변환 시간이 표시됩니다.
STEP 03

언어 선택 · 녹음 / 파일 첨부

새 노트 화면에서 언어를 먼저 선택한 뒤, 직접 녹음하거나 이미 있는 음성 파일을 올립니다.

03
노트 정보 입력 (선택)
상단 New note 에 제목을 적고, Folder(저장 폴더)와 Participants(참석자)를 지정합니다. 우측 Memo 칸에는 회의 중 메모를 남길 수 있습니다.
04
언어 선택
Transcript 영역 좌측 하단의 언어 드롭다운(예: Korean + English)에서 회의에 사용된 언어를 고릅니다. 파일 업로드 시에는 언어 선택이 먼저입니다.
05
녹음 또는 파일 첨부
① Record — 회의를 바로 녹음 · ② Attach file — 녹음 파일 선택 또는 드래그 앤 드롭. 업로드는 최대 180분, 지원 형식은 .m4a .mp3 .aac .amr .wav 입니다.
OPTION A
Record — 현장에서 바로 녹음
회의 시작 시 눌러 녹음하고, 끝나면 정지합니다. 녹음 내용은 스크립트로 변환됩니다.
OPTION B
Attach file — 기존 파일 업로드
휴대폰 · 녹음기로 이미 녹음한 파일을 올립니다. 언어를 먼저 고른 뒤 첨부하세요.
한국어 + 영어 혼용 회의라면 Korean + English 를 선택하면 두 언어가 섞여도 변환됩니다.
STEP 04

변환된 스크립트 확인하기

녹음(업로드)이 끝나면 노트가 만들어지고, 화자 · 시간 단위로 나뉜 스크립트가 표시됩니다.

A
Transcript
화자(Participants)와 시작 시간(00:00, 00:29 …)별로 본문이 나뉩니다. Edit 로 오탈자를 수정하고, Copy 로 전체를 복사할 수 있습니다.
B
재생 바
하단에서 녹음을 다시 듣고 확인할 수 있습니다(재생 · 배속 · 5초 앞/뒤 이동).
C
Summary · Memo
우측 탭에서 AI 요약과 메모를 봅니다. AI 요약 · 주요 키워드는 한국어 노트에서만 제공됩니다(키워드는 일본어도 가능).
D
상단 아이콘
우측 상단 공유 · 검색 · 다운로드(↓) · 기타(⋮) 아이콘이 있습니다.
영어 회의 노트는 캡처처럼 “Unable to summarize. AI summaries are only available in Korean.” 문구가 나오며, 스크립트만 제공됩니다.
STEP 05 · 06

스크립트 파일로 다운로드

노트 우측 상단의 다운로드(↓) 아이콘을 누르면 Download transcript? 창이 열립니다.

06
다운로드 창에서 선택
① 파일 형식 선택 → ② Include 에서 Timestamps(시간) · Participants(화자) 포함 여부 체크 → ③ Download. 취소는 Cancel.

파일 형식 선택 가이드

형식이럴 때 사용
Text (.txt) 기본값가장 가볍고 어디서든 열림. 내용 복사 · 붙여넣기용
Word (.docx)회의록 · 보고서로 편집해서 공유할 때 추천
Excel (.xlsx)화자 · 시간별로 표 형태로 정리하거나 필터링할 때
Hanword (.hwp)한글 문서로 제출 · 보관해야 할 때
SRT (.srt)영상 자막용 (일반 회의록에는 불필요)
Include 옵션 — Timestamps를 켜면 발언 시각이, Participants를 켜면 화자 구분이 함께 저장됩니다. 보고용 정리본이 필요하면 둘 다 끄고, 근거 확인이 필요하면 둘 다 켜 두세요.
TIPS

알아두면 좋은 점

화면에서 확인된 제한과 실무에서 자주 놓치는 부분을 정리했습니다.

LIMIT
잔여 변환 시간 확인
좌측 하단 Remaining transcription time(남은 변환 시간)과 Remaining summaries(남은 요약 횟수)를 녹음 전에 확인하세요.
FILE
파일 업로드 조건
1건당 최대 180분, 형식은 .m4a .mp3 .aac .amr .wav. 긴 회의는 파일을 나눠 올리는 것이 안전합니다.
LANG
언어를 먼저 선택
언어를 잘못 고르면 변환 품질이 떨어집니다. 한·영 혼용 회의는 Korean + English 를 선택하세요.
AI
요약 · 키워드는 한국어만
AI 요약은 한국어 노트에서만 제공됩니다. 영어 회의는 스크립트를 내려받아 별도로 정리해 주세요.

권장 작업 순서

BEFORE
회의 전
남은 변환 시간 확인 → New note 생성 → 제목 · 폴더 · 참석자 입력 → 언어 선택. 제목은 날짜_회의명(예: 2026 Oct 14_Preparation for IT black out) 형식으로 통일하면 검색이 쉽습니다.
DURING
회의 중
Record 로 녹음하고, 핵심 결정 사항은 우측 Memo 에 바로 적어 둡니다.
AFTER
회의 후
스크립트 확인 · Edit 로 수정 → 다운로드(.docx 권장) → 팀 공유 폴더에 저장.
녹음 전 반드시 참석자에게 녹음 사실을 알리고 동의를 구해 주세요. 대외비 · 고객 정보가 포함된 스크립트는 사내 보안 지침에 따라 보관 · 공유합니다.
참고 — 본 가이드는 제공된 화면 캡처를 기준으로 작성되었습니다. 메뉴 명칭 · 제한 수치는 ClovaNote 업데이트에 따라 달라질 수 있으니, 사용 전 실제 화면을 확인해 주세요.
